# Finora — Поток: первые 20 уровней

20 отдельных определений, шесть типов фишек, постепенное введение усилителей и препятствий. Числа — рабочий прототипный баланс, а не финальная настройка 500 уровней.

Для каждого уровня проверен хотя бы один выигрышный маршрут с реальными правилами движка. Это подтверждает существование прохождения, но не доказывает удобство, сложность или вероятность победы для человека.

Учебные поля 4–10, 12–14 имеют гарантированный первый ход для создания нужной фигуры. Поля 16–20 содержат готовую пару усилителей для обучения сочетаниям; другие фишки остаются обычными. Все начальные поля стабильны, готовых совпадений нет. Подсказка — реальные индексы клеток, не картинка.

Клетки индексируются от 0 до 63 по строкам 8 × 8. Для каждого прохождения сохранены seed, последовательность обменов, итоговые счёт и звёзды в `assets/flow/winning_replays.json`. Начальная раскладка также зафиксирована в определении уровня.

Воспроизведение: `source tool/cloud_env.sh`, затем `dart run tool/solve_flow.dart --verify`. Пересборка набора и поиск доказательных прохождений: `dart run tool/solve_flow.dart`. Поиск ограничен числом ходов и шириной луча 6; отсутствие решения приводит к ошибке, а не к заявлению о готовности.
