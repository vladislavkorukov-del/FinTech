# Subscription service artwork

The app bundles genuine Simple Icons SVG artwork for offline subscription recognition. Shapes are retained byte-for-byte; the UI uses the source brand hex color on a neutral contrast plate. No remote logo URLs are requested by the application.

- Source repository: https://github.com/simple-icons/simple-icons
- Pinned source commit: `4bfa9da744e2c06928047314ce30dc5c8d1ad759`
- Artwork licence: CC0-1.0, copied in [LICENSE-SIMPLE-ICONS.md](../assets/services/LICENSE-SIMPLE-ICONS.md). Any per-icon upstream licence metadata is retained in the manifest.
- Brand names and marks identify the corresponding services; this app is not affiliated with those services. A copyright licence for the icon collection does not transfer trademark rights.
- Product variants use the unchanged parent mark when no separate product mark exists: YouTube Premium → YouTube, VK Музыка → VK, Telegram Premium → Telegram, PlayStation Plus → PlayStation, Discord Nitro → Discord, SoundCloud Go+ → SoundCloud.

The catalog contains 62 services: 53 source SVGs and 9 entries with a neutral icon. Neutral entries deliberately do not claim a recreated logo: Яндекс Плюс, Google One, ChatGPT, Okko, Иви, Wink, START, KION, Microsoft 365. Users can choose an actual local image for any of these services.

## Updating and verification

Run `python tool/fetch_service_assets.py --verify` to verify every bundled SVG digest. Run `python tool/fetch_service_assets.py --fetch` to retrieve the same pinned originals with TLS and digest verification. This does not update the manifest or expected hashes. To update upstream artwork, deliberately review a new source commit, its licence, metadata, shapes and expected hashes before replacing the manifest.

## User images

Custom service images are copied unchanged into the application support directory under `service_icons/` with a random filename. The picker accepts PNG, JPEG and WebP, at most 2 MiB and 16 megapixels (each side at most 8192px). The original selected file is never moved or deleted. Canceled custom-service selections discard only the newly created managed copy. JSON/database portability is handled by the repository, independently from the logo catalog.
