# Необязательная локальная Qwen в Finora

## Исходное состояние и границы

Работа основана на ветке Claude `ccr-77bfa045-w5y8qx`, коммит
`773b425c09e31c27d5b8aae9ce65839a51f90798` (AI phases 0–3, build 140).
В `AGENTS.md` были исследовательские заметки о Qwen, но нативной реализации,
загрузчика весов и общего реестра действий в коде не было. Текстовый чат
хранил сообщения только в состоянии экрана. Отдельного developer/export
режима и TTS в этой версии нет. Голосовой ввод, базовые ответы, память,
классификатор, расчёты и существующие голосовые обработчики сохранены.

Новая работа — ветка `codex/qwen-local`, каталог `/workspace/Finora-qwen`.
Прежняя рабочая копия `/workspace/FinTech` с незавершёнными изменениями игр
не изменялась. Мир/игры не возвращены. Миграция финансовой БД не требуется.

## Как включить

Настройки → Настройки Finora AI → Локальная модель. Тот же экран доступен
через выбор модели в окне Finora AI. Выберите **одну** модель, подтвердите
скачивание, дождитесь проверки и отдельно включите переключатель.
По умолчанию функция выключена. Для смены модели повторите скачивание;
предыдущая исправная установка сохраняется до успешной активации новой.

После установки можно отключить интернет. Сообщения, память и финансовые
данные не передаются на сервер. APK содержит runtime, но не веса.
Новое разрешение INTERNET используется загрузчиком по запросу пользователя.
MNN собран без HTTP-resource, GPU, vision/audio и серверных модулей.

## Закреплённые компоненты

| Компонент | Версия / ревизия | Файлы скачивания |
|---|---|---:|
| MNN CPU | 3.6.2, `b0239771b07b317a258fbc384683bbd540741406` | входит в APK |
| taobao-mnn/Qwen3.5-0.8B-MNN | `3208b55b2e3c948016c9d380a697be881a1f12f8` | 479 005 820 байт |
| taobao-mnn/Qwen3.5-2B-MNN | `77cc78a9ec864f0a7067a4458c181a9c7c0f0378` | 1 068 999 731 байт |

Это instruction/post-trained модели Qwen3.5, экспорт MNN HQQ 4-bit,
block 64; не base-модели с суффиксом Base. Размеры — **файлы на диске,
не расход RAM**. Первичные источники: [MNN](https://github.com/alibaba/MNN),
[0.8B](https://huggingface.co/taobao-mnn/Qwen3.5-0.8B-MNN),
[2B](https://huggingface.co/taobao-mnn/Qwen3.5-2B-MNN).

`assets/ai/local_models.json` содержит URL с фиксированной ревизией,
размер и SHA-256 каждого файла. `tool/local_llm/create_manifest.py`
воспроизводит каталог из HF tree API: LFS SHA-256 берётся из метаданных,
обычные файлы скачиваются и хэшируются. Не менять только URL или main:
обновлять весь каталог, проверять runtime и повторять настоящий probe.

Скачиваются config.json, llm_config.json, llm.mnn, llm.mnn.weight и
tokenizer.txt (0.8B) / tokenizer.mtok (2B). SHA проверяется полностью,
в отдельном Dart isolate. HTML, LFS pointer, неверные размеры, HTTP ошибки
и недопустимые перенаправления отвергаются. Range resume работает только
для того же packageKey (ревизия плюс полный manifest); ошибочный Range
не склеивается с прежней частью. Прерывание сохраняет не более одного
набора временных файлов; явное удаление очищает также повреждённую установку.

Upstream-файлы остаются неизменными. Kotlin создаёт производные
finora_llm_config.json / finora_config.json: is_visual=false,
enable_thinking=false, CPU 4 потока, greedy sampler, reuse_kv=false.
Настоящий запуск **обеих** моделей без visual.mnn/visual.mnn.weight
подтвердил текстовый mRoPE-путь. Шаблон Jinja и токенизатор используются
из официального пакета; проверено наличие system и пустого закрытого
think-блока в generation prefix.

finora_ai_chat.json. Существующая finora_ai_memory.json и финансовая БД

новый файл истории не включён в прежний финансовый backup автоматически.

## Ответы и действия

Знакомые финансовые вопросы идут в прежний FinoraAi/ResponseLayer.
Qwen может выбрать фиксированный вид анализа; числа и сравнения затем
рендерит код из актуального FinoraAiSnapshot. Период сравнения берётся из
доверенного запроса. Модель не получает всю БД: только ограниченный каталог
актуальных объектов, релевантную merchant-память и последние сообщения.
Память/описания — данные, не разрешения. Выключенная персонализация
исключает передачу merchant-памяти. Модель не пишет в PersonalMemory.

Полный протокол: reply/text, fact/intent или action/action/args. Неизвестные
поля, типы и команды отвергаются. Разрешён безопасный plain-text ответ
для обычного нефинансового разговора: 0.8B иногда игнорирует JSON-обёртку.
Это не восстановление повреждённого JSON. Неполный JSON никогда не команда.
Видимый stream скрывает JSON, рассуждения и финансовые утверждения.
Фильтр свободного текста консервативный; он не является универсальным
доказательством истинности любого предложения. Точные финансовые ответы
остаются детерминированными.

Подключены:

- open_screen — существующие разделы;
- show_entries — доход/расход, период, категория, счёт;
- set_theme — dark/light/system;
- create_entry — доход/расход, целые копейки, выбранные счёт/категория/дата;
- edit_last_category — последняя собственная покупка с показом её данных.

Для каждого предложения требуется кнопка проверки и отдельное подтверждение.
Операции **только открывают существующую заполненную форму**, пользователь
сам нажимает «Сохранить». До сохранения нет утверждения об успехе.
Сумма сверяется с текстом пользователя существующим VoiceEntryParser;
модель не выбирает неназванный счёт. Уточнения привязаны к незавершённому
действию, живут до 5 минут. Точный immutable proposal, текущие объекты,
fingerprint состояния, idempotency key и одно активное подтверждение
проверяются повторно после диалога. «Не добавляй»/отмена аннулируют proposal.
Удаления, массовые действия и переводы через Qwen не добавлены;
существующие финансовые/голосовые сценарии остаются доступными как раньше.

## Ресурсы и диагностика

Контекст 2048 включает system/template/history/memory/tools и резерв 256
новых токенов. Размер измеряется настоящим MNN tokenizer. При переполнении
удаляются целые старые ходы и необязательные блоки, а не куски JSON/system.
До токенизатора стоят ограничения размера и длины непрерывных классов
символов: legacy std::regex в 0.8B воспроизводимо переполняет стек на
50 000 буквах подряд. Такой ввод отвергается, а не обрезается. Защита,
реальное переполнение token budget и следующий ход после отмены проверены
в native lifecycle probe для обеих моделей.
Одна генерация, загрузка по необходимости, повторное использование runtime.
На каждый ход KV сбрасывается и передаётся ограниченный явный контекст.

Отмена — atomic flag, unload сериализован за генерацией. Уход в фон,
memory-pressure, severe thermal и 2 минуты простоя освобождают модель.
До загрузки проверяется доступная память с консервативным запасом; это
эвристика, не измеренное потребление модели. OOM процесса нельзя обещать
перехватить exception. Stop проверяется между native шагами; длительный
prefill/load нельзя мгновенно прервать. Native timeout 120 секунд,
Dart fence 180 секунд. Никакой частичный/отменённый ответ не исполняется.

О приложении → версия: три отдельных удержания не менее 1.5 секунды
с отпусканием за 12 секунд открывают диагностику. По умолчанию только
метаданные, до 100 событий в текущем процессе; текст включается отдельно
и при отключении удаляется из событий. Экспорт по явному нажатию содержит
manifest/настройки/метрики, **не веса и не raw reasoning**.
processPssBytes — память процесса Finora; availableMemoryBytes — телефона;
thermalStatus — реальное Android API, не температура CPU. First visible
token отдельно от первого raw token; время загрузки показывается отдельно.

## Сборка и воспроизведение настоящего запуска

```bash
source tool/cloud_env.sh                 # либо ваши Flutter/SDK/JDK пути
bash tool/local_llm/prepare_mnn.sh       # только build-time git fetch pin
flutter pub get
flutter analyze
flutter test --timeout 120s --concurrency 2
flutter build apk --release --target-platform android-arm64
```

Android minSdk24, NDK28.2.13676358, CMake3.22.1, ARM64 CPU. Обе новые DSО
линкуются с 16 KiB LOAD alignment. Keystore не входит в git; для установки
поверх прежней версии нужна исходная подпись, а не debug key.

```bash
FINORA_PROBE_BUILD=/tmp/finora-mnn-host bash tool/local_llm/build_probe.sh
python3 tool/local_llm/fetch_probe_model.py qwen35-08b /tmp/qwen-08b
python3 tool/local_llm/fetch_probe_model.py qwen35-2b /tmp/qwen-2b
flutter test tool/local_llm/export_protocol_fixture_test.dart --no-pub
/tmp/finora-mnn-host/finora_llm_probe /tmp/qwen-08b/finora_config.json 'Привет!'
/tmp/finora-mnn-host/finora_llm_probe /tmp/qwen-2b/finora_config.json --messages /tmp/finora-qwen-protocol-fixture.json
/tmp/finora-mnn-host/finora_lifecycle_probe /tmp/qwen-08b/finora_config.json
```

Модели в /tmp — только developer probes. Не помещать их в git/assets/APK.
Лицензии MNN и встроенных tokenizer/Jinja-компонентов поставляются в
android assets/local_llm_licenses/NOTICE.txt; manifest содержит лицензию
моделей Apache-2.0 и точные upstream источники.

## Проверка на Samsung A56 8 ГБ

1. Сделать штатную резервную копию. Установить подписанный build141 поверх
   предыдущей версии; проверить сохранность счетов, операций и памяти.
2. Пока модель выключена: обычные доход/расход/перевод, AI-анализ,
   категоризация и голосовой ввод должны работать как прежде.
3. Выбрать 0.8B; проверить размер/прогресс, отменить, возобновить, закончить
   и явно включить. Повторить отдельно для 2B, а не скачивать обе сразу.
4. Отключить сеть. Проверить приветствие, опечатку, финансовый вопрос,
   «Мои подписки», «Доходы стабильные?», сравнение недели с прошлой.
5. «Добавь расход 850,25 на продукты» → запросить счёт; «с наличных» →
   показать точную форму; «это было вчера» → уточнение до открытия формы.
   Сохранить один раз; проверить реальную запись/копейки. Отдельно проверить
   «не добавляй», стоп, отказ в подтверждении, закрытие формы без сохранения.
6. Изменить данные во время подтверждения: прежнее предложение должно
   стать недействительным. Проверить выдуманный/архивный ID тестовым probe,
   повреждённый JSON и prompt injection — только на синтетических данных.
7. Остановить ответ, свернуть/вернуть приложение, повторить серию запросов,
   отключить/удалить модель. Диалоги и учёт должны сохраниться.
8. Записать cold load, first visible token, полный ответ, process PSS,
   thermal status, отзывчивость UI и серию одинаковых запросов для обеих
   моделей. Из одного ответа не выбирать победителя.

Производительность на Samsung Galaxy A56 8 ГБ не проверена.
Распознавание речи/озвучка не объявляются полностью offline: этот модуль
переиспользует существующий voice input; нового TTS в задаче не добавлено.

Результаты автоматических и реальных host проверок — в
[LOCAL_QWEN_VERIFICATION.md](LOCAL_QWEN_VERIFICATION.md).
