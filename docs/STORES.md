## Распознавание получателя

Регистр, «ё», знаки препинания не важны. Банки пишут после бренда филиал, город или номер, поэтому
подходит и начало строки: «MAGNIT MM KOSTROMA», «Пятёрочка 1234», «OZON.RU», «YANDEX*GO», «DNS-SHOP».
Нужно целое слово: «Магнитогорский рынок» — не Магнит. Если подходят два бренда одинаково — логотипа
нет, приложение не угадывает. Подписки сохраняют прежнее точное совпадение: «Wildberries»,
«Вайлдберриз» и «Озон» по-прежнему означают WB Джем и Ozon Premium (у них тот же родительский знак).

## Откуда логотипы

Каждый логотип — иконка, которую публикует **официальный сайт бренда** (apple-touch-icon / иконка
сайта). Многие российские сайты не открываются из среды сборки (сертификаты российского УЦ, защита от
ботов), поэтому файл взят через публичный сервис иконок сайтов, который отдаёт именно иконку этого
сайта: Google (71), Яндекс (22); Мираторг — напрямую с miratorg.ru. Для каждого записаны сайт, URL
загрузки, дата, SHA-256 исходного файла и копии для показа (`assets/stores/manifest.json`).
Исходные файлы лежат байт в байт; для показа сделана PNG RGBA без изменения размера и цветов
(`assets/stores/raster`). Права на знаки принадлежат владельцам брендов; знак используется только
чтобы узнать получателя, одобрения не подразумевается.

Каждая иконка просмотрена глазами. **Без логотипа (остаётся значок категории):**

- METRO, Верный, Stars Coffee, Эльдорадо, Такси Максим, Лукойл, Татнефть, Госуслуги, СберЗдоровье —
  сайт публикует только значок 16–48 px; растянутая копия размыта, не используется.
- SPAR — сервис вернул повреждённую чужую картинку; Светофор — официальный сайт сети не подтверждён.
- OBI — obi.ru отдаёт значок «ДОМ Лента», смена бренда не подтверждена; Boxberry — сайт перенаправляет
  на Яндекс Доставку.
- Яндекс Драйв — иконка не найдена.

Обновление и проверка:

```sh
python3 tool/store_catalog.py --fetch          # скачать заново (затем просмотреть)
python3 tool/store_catalog.py --sheet /tmp/s.png
python3 tool/store_catalog.py --generate
python3 tool/store_catalog.py --verify
```
