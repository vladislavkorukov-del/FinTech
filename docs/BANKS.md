# Банки и кредитные организации (1.6)

## Реестр

Список — официальный справочник БИК Банка России (электронный документ ED807,
<https://www.cbr.ru/s/newbik>), рабочий день **05.11.2026**, дата ЭД 03.11.2026.
В каталог входят только участники с типом `PtType=20` — кредитные организации.
Филиалы, подразделения Банка России и казначейства не включаются: в них нельзя
открыть личный счёт.

- **364** кредитные организации, **365** БИК (у Совкомбанка два БИК).
- Для каждой: регистрационный номер (стабильный идентификатор, например
  `1481`, `3510-К`), все БИК, официальное наименование и город из справочника.
- НКО/РНКО помечены как небанковские кредитные организации (`НКО`).
- 50 крупных организаций имеют привычные названия и прежние имена для поиска:
  Сбер, Тинькофф → Т-Банк, Промсвязьбанк → ПСБ, ГПБ → Газпромбанк, Хоум Кредит,
  Ситибанк → РенКап Банк, Яндекс Деньги → ЮMoney и т.д. У остальных название
  получено из официального без организационно-правовой формы.
- Поиск: русские и латинские названия, сокращения, регномер, БИК, город; дефисы,
  кавычки и точки не мешают («т банк», «дом рф»). Точные совпадения — первыми.

Архив ED807 не хранится в репозитории; записаны SHA-256 архива и XML
(`assets/banks/registry.json`). Обновление:

```sh
curl -L -o /tmp/newbik.zip https://www.cbr.ru/s/newbik
python3 tool/bank_catalog.py --build /tmp/newbik.zip
python3 tool/bank_catalog.py --verify
```

Если регномер из списка брендов исчез из реестра (отзыв лицензии,
присоединение), сборка останавливается — бренд нужно убрать вручную, а не
показывать несуществующую организацию.

## Где видно в приложении

- **Библиотека иконок сервисов**: группа «Банки и кредитные организации»
  (например, для кредита или обязательного платежа банку). Прежние 246 сервисов,
  их ID, файлы и SHA не изменены.
- **Форма счёта**: у поля «Банк» кнопка выбора из реестра; выбор только
  заполняет название, в сеть ничего не отправляется.
- **Список счетов на главной и экран «Счета»**: если банк счёта распознан и у
  него есть оригинальный знак, он показан вместо значка счёта.

## Логотипы

**Состояние в этом коммите: оригинальных логотипов банков пока нет (0).**
Все 364 организации показываются с нейтральным значком банка — это не
фирменный знак. Кандидаты (оригинальные файлы Wikimedia Commons с лицензией;
выбраны через Wikidata P154 и поиск Commons) отобраны для ~28 банков, но
Wikimedia отвечает 429 общему IP среды сборки, поэтому файлы ещё не скачаны
и не проверены визуально. Логотип добавляется только через
`tool/bank_catalog.py --fetch-logos/--render` с записью источника, лицензии и
SHA-256 в `assets/banks/manifest.json`.

Оригинальных файлов на Commons не нашлось для Газпромбанка, Россельхозбанка,
МКБ, Банка «Санкт-Петербург», Экспобанка, Локо-Банка, БКС, Финама,
Новикомбанка и Почта Банка (последний в реестре ED807 уже отсутствует). Для них
логотип не рисуется и не подменяется.
