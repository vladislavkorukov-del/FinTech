# FINORA: Магистрали — архитектура

Экономика и симуляция — чистый Dart без Flutter (`lib/domain/magistrali`).
Отрисовка и интерфейс — Flutter + Flame (`lib/presentation/screens/world/magistrali`).
Сохранение — отдельный файл игры (`lib/services/magistrali_store.dart`),
никак не связанный с базой бухгалтерии Finora.

## Принципы

- **Детерминизм.** Один seed — одна карта; одинаковые действия дают
  одинаковый результат; сохранение посреди рейса продолжается точно.
- **Версия генератора карты** хранится в сохранении: старые партии
  восстанавливаются генератором 1 клетка в клетку, новые используют
  генераторы 2–4. Каждый следующий генератор только добавляет предприятия
  в конец списка — карты прежних версий не меняются.
- **Учёт грузов.** Всё, что существует (склады предприятий, входные склады,
  грузы в машинах, кладовые и запасы роста поселений), равно «создано −
  израсходовано». Загрузка проверяет баланс и отклоняет испорченный файл.
- **Резервы** не хранятся отдельно, а суммируются из заказов.
- **Территория поселения** — набор клеток (`y*1024+x`); проверки занятости,
  точек остановки и поиска пути работают по клеткам; для обычных
  предприятий — прежний квадрат.
- **Сохранения:** временный файл + резервная копия + атомарная замена;
  старый формат сохраняется как `world.vN.json` перед первой записью нового.

## Отрисовка

- `mag_game.dart` — Flame `Game`: кэш местности по чанкам, дороги, объекты
  с сортировкой по глубине, подписи, всплывающий доход.
- `mag_buildings.dart` — предприятия и поселения (застройка по клеткам и
  уровню), `mag_art.dart` — местность, дороги, деревья, машины,
  `mag_shapes.dart` — объёмные примитивы, `mag_sprites.dart` — замена
  фигур спрайтами PNG/WebP.
- Панели: `mag_hud.dart`, `mag_tools.dart`, `mag_sheets.dart`,
  `mag_fleet.dart`, `mag_routes.dart`, `mag_orders.dart`,
  `mag_warehouse.dart`, `mag_tech.dart`, `mag_dispatch.dart`, `mag_town.dart`,
  `mag_development.dart` (контракты развития), `mag_road.dart` (окно дороги),
  `mag_finance.dart` (финансовый центр), `mag_city.dart` (город в окне
  поселения), `mag_city_art.dart` (постройка специализации), `mag_industry_art.dart` (рисунки
  предприятий промышленности).

## Журнал и финансовый центр

Все деньги проходят через `_spend`, `_earn`, `_assetSale` (`world.dart`):
каждая операция — запись журнала с id, типом, категорией и источником, и
строка месяца (`MagMonth`). Финансовый центр (`world_finance.dart`) ничего
не хранит сам: он считает периоды из месяцев (тип категории — по
`MagJournal.kindOf`), а показатели машин, предприятий и поселений берёт из
их накопленных полей (`costs`, `emptyCells`, `revenue`, `delivered`,
`since`), которые пишутся в момент самой операции.
