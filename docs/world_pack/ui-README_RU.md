# Финора — отдельные иконки

15 самостоятельных иконок + 1 декоративная веточка, PNG RGBA с настоящей прозрачностью. Каждая иконка отрисована отдельно по утверждённому макету. Иллюстрации могут немного отличаться в деталях от исходного общего листа.

## Подключение

Скопируйте папку png в каталог ресурсов приложения. Используйте manifest.json как таблицу идентификаторов. Пути в манифесте заданы относительно корня набора.

Сохраняйте пропорции: contain / aspect fit, без растягивания и обрезки. У PNG есть прозрачные поля. Для визуального выравнивания настраивайте размер изображения в контейнере индивидуально; круглые кнопки также нужно визуально выровнять между собой. Файлы оставлены в исходном качестве.

Рекомендуемый видимый размер: иконки разделов 64–96 CSS px, служебные кнопки 32–48 CSS px, значки счётчиков и звука 20–32 CSS px. На мобильных устройствах область нажатия должна быть не меньше 44 × 44 CSS px. Веточка — декоративный элемент; её пропорции отличаются от квадратных иконок.

back.png, settings.png, close.png, add.png уже содержат круглую подложку. rank_badge.png содержит медальон. games.png содержит арку. background.png и decor.png содержат только предметы без круглой подложки. Не добавляйте повторную подложку поверх готовых кнопок.

Подписи, значения валюты, опыт, прогресс, переключатели, панели и большие текстовые кнопки создавайте средствами интерфейса. Они не включены в иконки. Для точного направления стиля смотрите source/approved_style.png. Цвета: жемчужный, мятный, лавандовый, тёмно-сливовый текст и тонкие акценты шампань.

Эти картинки сами по себе не добавляют действия кнопок: обработчики подключаются к существующим экранам проекта.
