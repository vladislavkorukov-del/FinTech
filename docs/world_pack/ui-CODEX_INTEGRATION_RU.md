# Задание для Codex: подключение иконок Финоры

Подключи приложенный набор к существующему «Миру Финоры». Сначала изучи структуру проекта и его инструкции. Используй source/approved_style.png как визуальный ориентир и manifest.json для соответствия файлов элементам.

1. Перенеси png в принятый в проекте каталог статических ресурсов, подключи его через текущую систему ассетов.
2. Сопоставь все 15 иконок элементам по manifest.json и README_RU.md. Декоративную веточку используй только как украшение панели.
3. Сохрани существующие маршруты, обработчики, игровые данные и логику финансового приложения. Изменения ограничь «Миром Финоры».
4. Используй aspect fit / object-fit: contain. Сохрани прозрачность, не меняй цвета фильтрами. Визуально выровняй размер объектов с учётом прозрачных полей; не растягивай изображения. У кнопок back/settings/close/add уже есть подложки.
5. Надписи и счётчики реализуй обычным текстом, прогресс и переключатели — компонентами интерфейса. Не используй общий макет как рабочую картинку экрана.
6. Названия разделов: «Гардероб», «Питомцы», «Сад», «Альбом», «Игры», «Фон», «Декор». Значок духа обозначает раздел питомцев, а не заменяет основную Финору.
7. У кнопок должны быть доступные названия и состояния фокуса/нажатия; декоративные картинки скрой от скринридера. Сохрани текущий способ хранения настроек звука и музыки.
8. Проверь загрузку всех файлов, существующие переходы, отсутствие обрезки и наложений на узком и широком экране. Выполни применимые проверки проекта и перечисли изменённые файлы.

Набор содержит только изображения и инструкции, готовой интеграции в исходный код в нём нет.
