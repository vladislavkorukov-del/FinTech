## Чек → одна операция

Новый `test/receipt_total_v16_test.dart` (7 сценариев). До исправления 3 падали: итог в правой колонке (по координатам), «И Т О Г»/«ИT0Г»/«К 0ПЛАТЕ», отсутствие итога (раньше бралась сумма способа оплаты). Покрыто: много цен + НДС + внесено + сдача → один итог; итог на следующей строке; потерянная шапка; неоднозначный итог → пусто; банковская страница → 4 операции, зарплата — доход. Прежние parser/statement/scan-import/editor тесты проходят без изменений. Подробнее — [OCR.md](OCR.md#receipt-total-in-16). Данные синтетические, не фото реальных чеков.

## Главная

Тесты в `finance_v12_interface_test.dart`: баланс и валюта по центру шапки при 320/412dp и шрифте 1.0/1.6, F и изображений в шапке нет; настройки, «Моя семья» и нажатие на баланс (→ «Счета») работают. Порядок: шапка → доходы/расходы месяца → действия (зазор ≤12dp) → «Все счета», при 320×740 (текст 1.4), 412×900 и 740×360. Отдельной карточки баланса нет. Три кнопки одинаковой ширины, высота ≥48dp, каждая открывает свою форму. `widget_test`: нет переполнений в светлой/тёмной теме при 320×640 и 740×360. Тест F перенесён на загрузочный экран (там F осталась). [Превью](images/finance-1.6.0-dashboard.png) — Flutter renderer, демоданные, не снимок телефона.

`test/bank_catalog_v16_test.dart`: каталог совпадает с записанным реестром; регномер/БИК; поиск «сбер», «тинькофф», «т-банк», «ГПБ», «псб», «юмани», «дом рф», БИК; 246 сервисов и прежние поиски не изменились. UI: выбор банка в форме счёта; банк без логотипа — нейтральный значок. Логотипов пока нет: Wikimedia (и API, и upload) отвечал 429 общему IP среды сборки весь сеанс — см. [BANKS.md](BANKS.md).
