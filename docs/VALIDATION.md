## Исправления, подтверждённые текущим прогоном

- Нижняя навигация больше не занимает высоту всего экрана.
- Кольцевая диаграмма адаптируется к узким карточкам и не переполняется.
- Категории используют актуальный onReorderItem с правильным индексом.
- Устранены все замечания анализатора, включая асинхронные обращения к контексту.
- Android-плагин уведомлений корректно зарегистрирован в тестовом окружении; тесты очереди и календарных повторений выполняются.
- UI-тесты прокручивают ленивые формы до целевого элемента и закрывают fullscreen-редактор реальной кнопкой Close.

## Покрытие

Тесты проверяют балансы и границы денежных агрегатов, обе стороны переводов и валюты, pending/cancelled, бюджеты, статистику, anchorDay, реальную SQLite FFI, сохранение/повторное открытие, атомарный импорт и восстановление, переносимые чеки, CSV, сохранение личных записей при очистке демо, PIN/PBKDF2/lockout, расписание уведомлений, цифровую панель, темы, маленький экран320×640 и landscape740×360, блокировку поверх вложенного редактора и последовательность импорта/записей.

## Подготовленная среда

Полный JDK21.0.13+9 установлен из официального Temurin release с проверкой SHA-256; Java использует системный CA store, включая сертификат прокси, без отключения TLS. Для native-плагинов установлены SDK34/35/36, Build Tools36.0.0, NDK28.2.13676358 и CMake3.22.1. Java HTTPS-запрос к официальному Android repository проверен: HTTP200. Все изменённые shell/Python setup helpers прошли синтаксическую проверку и повторную проверку установленных компонентов.

Сетевой блокер предыдущей среды устранён публикацией, выполненной пользователем. Агент повторно ничего не публиковал и не применял старый черновик.

## Ограничения

Семейный профиль локален на одном устройстве; cloud sync не подключён. Автоматические операции создаются при открытии/возобновлении приложения. Курсы валют не загружаются, статистика раздельная по валютам. SQLite защищена Android sandbox и локальной блокировкой приложения; ручной экспорт не зашифрован. Биометрия, системные разрешения, доставка уведомлений и восстановление после reboot требуют отдельной проверки на реальном Android. Пройденные unit/widget-тесты и успешная сборка не заменяют такую проверку.
