# FINORA — Поток: террасная карта уровней

Готовая графика карты в стиле выбранного жемчужного сада: мраморные террасы, золотые кромки, мятные растения, лаванда и водоёмы.

## Что внутри

- `backgrounds/` — три PNG по 724×724 px. Вместе образуют непрерывный участок 724×2172 px.
- `png/` — десять отдельных элементов интерфейса с настоящим альфа-каналом.
- `preview/Map_Screen_Assembled.png` — пример собранного экрана.
- `preview/Map_Scroll_Demo.mp4` — демонстрация прокрутки собранной графики.
- `preview/Map_Icons_Overview.png` — обзор элементов.
- `preview/Map_Seams_Review.png` — крупные фрагменты трёх стыков.
- `preview/Map_Full_Period.jpg` — весь участок с примерами номеров уровней.
- `map_layout.json` — координаты площадок и предложенные размеры кнопок.
- `manifest.json` — размеры PNG и границы видимой части внутри прозрачных полей.
- `CODEX_INSTRUCTIONS_RU.md` — инструкция по встраиванию во Flutter.
- `SEAM_VERIFICATION.json` — результаты проверки экспортированных стыков.

## Порядок фонов

Сверху вниз: **A → B → C → A → B → C…**. Переход C → A также подготовлен. Изображения не нужно отражать или накладывать друг на друга. Отдельная секция сама по себе не является бесшовной; использовать именно указанную последовательность.

Секции вырезаны из одной непрерывной иллюстрации, а место замыкания предварительно дорисовано. Проверено точное восстановление общего изображения из экспортированных PNG и непрерывность рисунка на циклическом стыке. Прокрутка в MP4 — демонстрация сборки графики, не запись из Flutter-приложения.

## Элементы интерфейса

| Файл | Назначение |
| --- | --- |
| `map_node_completed.png` | Пройденный уровень, жемчужный диск с полочкой для звёзд |
| `map_node_available.png` | Доступный уровень, жемчужный диск |
| `map_node_current.png` | Текущий уровень, мятный диск |
| `map_node_locked.png` | Закрытый уровень, лавандовый диск |
| `map_lock_closed.png` | Отдельный замок |
| `map_star_earned.png` | Заработанная золотая звезда |
| `map_star_empty.png` | Незаработанная лавандовая звезда |
| `map_header_base.png` | Основа верхней панели |
| `map_button_back.png` | Кнопка назад со стрелкой |
| `map_label_levels.png` | Отдельная надпись «Уровни» |

Кнопки, звёзды и замок — 512×512 px с прозрачными полями. Панель и заголовок — 1024×341 px с прозрачными полями. Звёзды и основа панели повторно использованы из ранее согласованного интерфейса Finora; остальные элементы подготовлены отдельно для карты.

Номера уровней и количество звёзд не запечены в кнопки. Они меняются программно вместе с прогрессом. Числа на собранных превью — пример состояния, а не часть PNG-кнопок.
