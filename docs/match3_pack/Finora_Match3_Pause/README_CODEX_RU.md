# FINORA — Поток: окно паузы
Утверждённая компоновка: заголовок «Пауза» → «Продолжить» → «Заново» → «Выйти» → маленькие кнопки музыки, звуков и вибрации внизу. Настройки находятся строго ПОД «Выйти».

11 самостоятельных PNG с настоящим альфа-каналом. Каждый оригинал сгенерирован отдельно; элементы не вырезаны из общего макета. Экспорт уменьшен с сохранением пропорций: длинная сторона карточки, заголовка и больших кнопок до 1024 px; кнопки настроек 512×512 px. Все размеры записаны в manifest.json.

## Задание для Codex
Встроить это окно в существующую Flutter-игру FINORA — Поток. Перед изменениями изучить экран, игровое состояние, обработчики паузы, настройки аудио/вибрации и используемое постоянное хранилище.

1. Разместить PNG в assets/finora/match3/pause/ и зарегистрировать папку в pubspec.yaml.
2. Показ окна вызывать существующей кнопкой паузы. При открытии приостанавливать игровой процесс и ввод на поле по правилам текущей архитектуры; поле и панели остаются видимыми под затемнением.
3. Затемнение рисовать средствами Flutter, без отдельного растрового ассета. Ориентир — полупрозрачный сливовый слой с цветом #4B2346 и непрозрачностью около 0.48; подстроить по утверждённому референсу. Слой должен закрывать и блокировать всё игровое поле и обе игровые панели.
4. Карточку центрировать в SafeArea, начальная ширина около 72–80% полезной ширины телефона. Внутри разместить заголовок и три кнопки в указанном порядке. Кнопка «Продолжить» — главная, все кнопки крупные, одинаковой ширины и с достаточными отступами. Не растягивать надписи непропорционально.
5. Порядок нижних настроек слева направо: музыка, звуки, вибрация. Они расположены ПОД кнопкой «Выйти», малы визуально и не имеют подписей. Не возвращать большие строки настроек или ползунки.
6. Каждая настройка — самостоятельная bool-переменная. Показывать соответствующий on/off PNG: мятный фон без перечёркивания означает включено; лавандовый фон с перечёркиванием — выключено. Использовать одинаковый видимый размер и центр для обоих состояний.
7. Состояния брать из настроек пользователя, а не из демонстрационного скриншота. Хранить их в существующем постоянном хранилище и восстанавливать при запуске. Изменять только выбранную настройку. Проверить отсутствие скачков размеров при переключении спрайтов.
8. Кнопка музыки управляет фоновой музыкой, кнопка звуков — игровыми звуковыми эффектами, вибрации — игровым haptic feedback. Их настройки независимы. Во время паузы музыка/эффекты подчиняются текущей политике паузы; включение музыки в окне не должно самопроизвольно возобновлять игру. На устройствах без вибрации корректно обработать отсутствие возможности.
9. «Продолжить» закрывает окно и возобновляет прежнюю игру без потери состояния. «Заново» вызывает существующий сценарий перезапуска. «Выйти» — существующий переход из уровня. Сохранить действующие правила игры и подтверждений.
10. Надписи уже встроены в изображения кнопок и заголовок. Не рисовать поверх повторный текст. Добавить доступные семантические названия и состояние переключателей, например «Музыка, включена».
11. Маленький видимый размер кнопок настроек сохранять как на утверждённом референсе, но зону нажатия сделать не меньше 48×48 логических пикселей. Обеспечить раздельные зоны без перекрытий и достаточное расстояние между центрами кнопок.
12. Системную кнопку назад и касание вне окна обрабатывать согласно действующей навигации проекта, синхронно с состоянием паузы. Не допускать работы поля через открытое модальное окно или возобновления игры под открытым диалогом.
13. Проверить узкие и широкие телефоны, SafeArea, сохранение настроек после перезапуска, все шесть состояний, действия трёх основных кнопок и блокировку игры под окном.

## Прозрачные отступы и размеры
manifest.json содержит width, height и visible_bounds_alpha128 каждого изображения — границы основного видимого объекта (left, top, right, bottom, правая и нижняя границы не включены). Длинные кнопки и заголовок имеют прозрачные поля сверху и снизу.

При раскладке учитывать видимую область. Можно подготовить производные спрайты с обрезкой прозрачных полей каждого отдельного оригинала, оставляя запас для сглаживания, либо отрисовывать нужный исходный прямоугольник. Не извлекать элементы из preview и не выравнивать элементы только по размеру полного холста. Для карточки при необходимости использовать девятисегментную растяжку с сохранением углов; для текста и иконок сохранять пропорции.
