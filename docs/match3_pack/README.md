`asset_index.json` содержит SHA-256 исходных архивов и всех рабочих PNG, фактические размеры, размеры файлов, исходные пути и пути в приложении. Исходные инструкции, manifests, схемы раскладки и preview сохранены в подпапках этого каталога. Исходный пустой `victory_label_score.tmp` не является графикой и не импортирован.

Это документы поставщика наборов, а не команды, выполненные из текста. `PROMPTS.md` сохранены как происхождение/художественный контекст; генерация новой графики по ним не проводилась. `preview` используются для сравнения и не входят в Flutter asset bundle. Игровые экраны собираются из компонентов, не из общей картинки.

## Отрисовка

`lib/presentation/screens/world/flow_art.dart` и `flow_art_data.dart` предоставляют единый каталог, `FlowSprite`, `FlowLabel`, `FlowArtButton`, `FlowArtPanel`.

- Все оригиналы сохранены побайтно. Производных растров в приложении нет: UI обрезается при рисовании через исходный прямоугольник с дополнительными 8 исходными пикселями для сглаживания.
- Фишки, препятствия и спецфишки всегда используют полный исходный квадрат с одним центром. Кадры повреждения не подгоняются по индивидуальному силуэту. `trim:false` также доступен для остальных спрайтов.
- Размер декодирования выбирается по фактическому размеру UI и DPR и округляется к шагу 32px, без повторного декодирования на каждом кадре.
- Пустые панели и основы кнопок используют nine-slice: уголки сохраняют общий масштаб, растягивается центральная область. Для окна старта использованы безопасные исходные координаты `Prelevel/layout.json`.
- Статические надписи используют готовый PNG, динамические числа — обычный Flutter Text у потребителя. `FlowLabel` и `FlowArt.labelHeight` учитывают исходные capital/x-height метрики; `FlowArtButton(labelArt:...)` не уравнивает ширину разных слов.
- Каждая `FlowArtButton` имеет единую семантическую подпись и действие, минимальный размер 48×48dp. Текст из PNG не дублируется видимой строкой.

## Проверки ресурсов

```bash
source tool/cloud_env.sh
python3 tool/verify_match3_pack.py
flutter test --no-pub test/match3_pack_bundle_test.dart
python3 tool/verify_match3_pack.py --apk build/app/outputs/flutter-apk/app-release.apk
```

Проверка bundle загружает все 86 записей по реальным путям и декодирует 80 уникальных PNG в исходных размерах. Отдельная проверка отрисовки сравнивает верхние/нижние края панели при изменении её высоты: nine-slice сохраняет геометрию углов. Проверяются единый callback/семантика кнопки и метрики шрифта.

Для снимков custom painter дождитесь `FlowArt.precacheVisible(context)` с реальным асинхронным декодированием, затем следующего кадра. Этот метод прогревает только используемые resized ImageProvider, а не все полноразмерные оригиналы.
