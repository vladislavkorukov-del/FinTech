# FINORA — Поток: спецфишки

Три новых самостоятельных PNG 1024×1024 px с настоящим альфа-каналом:

| Файл | Назначение |
| --- | --- |
| `png/match3_rocket_horizontal.png` | Ракета, очищающая строку |
| `png/match3_rocket_vertical.png` | Ракета, очищающая столбец |
| `png/match3_rainbow_sphere.png` | Сфера, убирающая фишки выбранного типа |

Каждый предмет создан отдельным изображением. Вертикальная ракета подготовлена по образцу горизонтальной с сохранением света сверху слева, а не простым поворотом готового растра.

Бомба уже отрисована. Использовать `booster_bomb.png` из прежнего `Finora_Match3_Bottom_HUD_8_PNG.zip`. Точный путь внутри архива и исходные размеры записаны в `ASSET_SOURCES_RU.md` и `REUSED_ASSETS.json`. Старая бомба и шесть обычных фишек в этом архиве не дублируются и не перерисованы.

`preview/Special_Pieces_Review.png` — общий обзор трёх новых предметов рядом с готовой бомбой. `preview/Special_Pieces_64px.png` — отображение при 64×64 на светлой и тёмной подложке. `preview/Special_Pieces_Field_Review.png` — техническая композиция на поле. Клетки на технических превью не являются новой графикой интерфейса; не извлекать из них ассеты.

`CODEX_INSTRUCTIONS_RU.md` — подключение графики и согласованная схема спецкомбинаций. `CODEX_FIRST_PLAYABLE_PROMPT_RU.md` — задание для первой рабочей сборки. `special_piece_render_map.json` — пути и назначения. `manifest.json` и `VALIDATION.json` — параметры экспорта и результаты проверок изображений.

Графика проверена на прозрачность, размер, ориентацию и читаемость в уменьшении. Код Flutter-приложения в этой задаче не изменялся; игровые эффекты и правила пока описаны в инструкции.
