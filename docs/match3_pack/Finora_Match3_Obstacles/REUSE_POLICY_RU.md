# Правило дальнейшей работы с графикой Finora

Перед созданием элемента проверять существующие наборы и файлы проекта. Если подходящий элемент уже отрисован, использовать его исходный PNG и существующий asset path. Не генерировать похожую замену ради другого экрана.

В новых пакетах перечислять источники повторно используемых элементов: имя файла, предыдущий архив и точный путь внутри него. Старые PNG не дублировать без необходимости.

Новые состояния действительно нового препятствия, недостающие надписи и отсутствующие элементы можно создавать отдельно. Изменение утверждённого дизайна существующего элемента делать по запросу пользователя, сохраняя исходник.

Общие макеты и технические превью нужны для проверки композиции. Не нарезать из них рабочие элементы и не запекать динамические числа, звёзды, замки или фишки в игровые фоны.
