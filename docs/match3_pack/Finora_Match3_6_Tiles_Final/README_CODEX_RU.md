# FINORA — ПОТОК: утверждённые игровые фишки

6 отдельных PNG 1024 × 1024 px с настоящим альфа-каналом.
Каждая фишка сгенерирована отдельно. Утверждённые рисунки сохранены; выполнен только технический экспорт из оригиналов к требуемому размеру 1024 × 1024. Файлы не вырезались из общего коллажа.

## Соответствие

- match3_coin.png — золотая монета с рельефными листьями и мягким гуртом;
- match3_wallet.png — лавандовый кошелёк;
- match3_goal.png — коралловая цель;
- match3_shield.png — бирюзовый щит;
- match3_receipt.png — жемчужно-персиковый чек;
- match3_chart.png — сине-индиговый график.

## Для Codex / Flutter

Подключи файлы из png к существующему renderer игры штатным способом проекта. Сопоставь типам coin/wallet/goal/shield/receipt/chart соответствующие изображения по manifest.json. Сохрани игровую логику, идентификаторы типов и данные уровней. Не создавай другой движок и не меняй расчёт совпадений из-за подключения графики.

Используй единый квадратный контейнер для клеток, сохраняй пропорции и прозрачные поля PNG. Не растягивай ширину и высоту независимо и не подгоняй каждую фишку по силуэту автоматически. Размер декодирования и кеширование выбирай по фактическому размеру клетки; не декодируй исходники заново на каждом кадре.

Сами фишки не содержат фонов поля, рамок клетки, подсветки выбора, анимаций, усилителей или препятствий. Эти части реализуются/подключаются отдельно. Прозрачность уже настоящая: не удаляй чёрный/белый фон алгоритмами, не перекрашивай изображения фильтрами.

Проверь отображение на телефоне, размер 64 × 64, одновременное присутствие всех типов, выделение и обмен, отсутствие обрезки и искажения. Цвет — не единственный отличительный признак; сохраняй формы и исходные цвета.
