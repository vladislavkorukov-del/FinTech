# Встроить окно перед стартом уровня FINORA — Поток

Изучи текущий Flutter-проект, маршруты Match-3, модель уровня, инвентарь усилителей и хранение прогресса. Встрой окно между выбором уровня на карте и запуском игрового поля. Используй существующее состояние приложения.

## Подключение графики

1. Импортируй только четыре новых PNG из `png/` этого пакета. Список и границы видимой части находятся в `manifest.json`.
2. Все готовые фишки и элементы интерфейса бери из проекта по именам из `ASSET_SOURCES_RU.md`. `REUSED_ASSETS.json` указывает точный предыдущий архив и путь в нём, если файл ещё не импортирован. Не генерируй замену и не вырезай рисунки из макета.
3. Основу окна бери из `out_of_moves_panel_base.png`. Для более высокой карточки используй nine-slice: сохраняй скругления и золотые края, растягивай центральную часть. Предлагаемый безопасный центральный прямоугольник рассчитан в `layout.json`; координаты относятся к исходному PNG. Не растягивай весь рисунок равномерно по двум разным масштабам.
4. Слово «Уровень» уже есть в `hud_level_label.png`; номер добавляй живым текстом. Для основной кнопки используй `victory_button_primary_base.png`, поверх — новую надпись «Играть». Лавандовую плашку ходов можно собрать из `out_of_moves_button_restart_base.png` с nine-slice; золотой кант согласуется с существующим интерфейсом.
5. Плашки счётчиков бери из `booster_counter_badge.png`, ячейки усилителей — из `booster_slot.png`. Для маленькой круглой кнопки закрытия используй пустую жемчужную основу `map_node_available.png` и штатный знак × поверх. Это адаптация готовых компонентов; не создавай новые растровые иконки.

## Композиция

Сравни с `preview/Approved_Prelevel_Mockup.jpg`. По центру — высокая жемчужная карточка, карта под ней мягко затемнена и размыта средствами Flutter. Никаких целей, звёзд, номеров, замков или кнопок не запекать в фон.

Сверху вниз:

- Заголовок «Уровень» и номер; маленькое закрытие справа.
- Плашка «Ходы:» и реальный лимит.
- «Цели уровня», затем равномерный ряд целей с числами под ними.
- «Усилители», затем ряд доступных стартовых усилителей.
- Большая мятная кнопка «Играть».

Основной цвет чисел около `#610738`. Размер, насыщенность и базовая линия всех чисел в ряду целей одинаковые. Сохраняй пропорции PNG и учитывай их разные прозрачные поля, используя метаданные видимых границ. Не ориентируйся только на полный размер картинки.

Для примера используются монета ×20, кошелёк ×15, щит ×10, лимит 25 и уровень 12. Подставляй реальные данные уровня. Для 1–3 целей центрируй ряд; при большем количестве адаптируй сетку и высоту карточки, не уменьшая текст до нечитаемого размера. В будущем препятствия смогут быть отдельными типами целей, когда появятся их ассеты и логика.

На небольшом экране соблюдай SafeArea и доступность основной кнопки; при необходимости прокручивай содержимое карточки. Не растягивай исходный портретный макет на весь экран как единую картинку.

## Усилители и действия

На макете показаны бомба, перемешивание и +5 ходов. Включай в этот ряд только те усилители, которые действительно разрешено применять до старта по текущей логике проекта. Наличие готовой иконки не означает необходимость менять её механику. Молоток перечислен в источниках на случай существующей поддержки, но добавлять его автоматически не нужно.

Ячейки переключаются нажатием. Выбранная получает мятную обводку и галочку; нарисуй их стандартными средствами Flutter поверх существующей ячейки. Эти состояния, затемнение фона и знак закрытия не требуют новых растровых ассетов.

Не списывай усилители при открытии, переключении выбора, закрытии окна или отмене. Фактический расход выполняй ровно один раз при успешном подтверждении запуска, через имеющийся механизм инвентаря. Предотвращай повторный запуск при двойном нажатии. Недоступные усилители не выбираются; не добавляй покупку, цену или рекламу без существующей логики продукта.

Крестик и системная кнопка назад возвращают на карту. «Играть» передаёт идентификатор уровня и выбранные разрешённые усилители в существующий запуск игры. Закрытие окна само по себе не должно тратить ход или менять прогресс.

## Проверка после интеграции

Проверь реальные цели и лимит ходов, состояния выбора, отмену без списаний, однократный расход при запуске и защиту от двойного нажатия. Проверь короткий и трёхзначный номер уровня, разное количество целей, небольшой экран и безопасные отступы. Кнопкам нужны семантические подписи и области нажатия минимум 48×48 логических пикселей. Используй существующие проверки проекта; исходный проект в этом пакете отсутствует.
