## Настоящие модели, не тестовый адаптер

Получены **полные** обязательные файлы обеих pinned-моделей. Все размеры
и SHA-256 повторно сверены с manifest. В каталогах не было visual-файлов.
MNN собран из закреплённого исходника для CPU x86-64; JNI использует тот
же Session, который собран для Android. На телефоне этот результат
не воспроизводился: `adb devices -l` пуст.

Последний probe использовал настоящий системный prompt из
`QwenChat.instructions(AiActionSession.promptSchema)`, один синтетический
счёт/категорию, вопрос «Привет! Как тебя зовут?», greedy, non-thinking,
2048 context / 256 answer. **797 настоящих токенов входа**.

| Модель | Ответ | Load, мс | Первый raw token, мс | Генерация с prefill, мс | Новых токенов |
|---|---|---:|---:|---:|---:|
| 2B | `{"kind":"reply","text":"Привет! Я Финора."}` | 8804.55 | 11744 | 14377.3 | 17 |
| 0.8B | `{"kind":"reply","text":"Привет! Я Финора. Как тебя зовут?"}` | 2651.61 | 6189.98 | 9482.98 | 23 |

Обе генерации завершились `completed`, после них — `MODEL_RELEASED`.
Probe запускался под `strace` с ошибкой ENETUNREACH для connect/sendto;
в network trace **не было сетевых системных вызовов**, только завершение
потоков. Это доказательство локального text inference на host, а не
проверка Android-сети, фонового поведения или голосового распознавания.

Это единичные замеры на нагруженном сервере во время сборки/тестов.
Они не показывают комфортность на A56 и не выбирают победителя.
Raw-token latency не выдаётся за first visible token приложения.
Процессные Android PSS/thermal и first visible token нужно получить
на телефоне через добавленную диагностику.

Для **обеих** моделей отдельно прошёл настоящий lifecycle probe:

```text
CROSS_THREAD_CANCEL=cancelled
PATHOLOGICAL_INPUT_REJECTED
CONTEXT_OVERFLOW_REJECTED
REUSE_AFTER_CANCEL=completed
RELEASED
```

До input guard воспроизведён SIGSEGV на 50 000 буквах `A` в legacy
0.8B tokenizer. Backtrace показал рекурсию std::regex `_M_dfs` /
`_M_rep_once_more`. Исправление ограничивает размер и длину непрерывных
классов символов **до** токенизации, не режет JSON или текст. Probe теперь
также проверяет обычное переполнение реального token budget на множестве
коротких слов, затем успешное использование той же сессии после отмены.

## Что выяснилось о качестве

- Обе модели поддерживают настоящий русский text inference, но допускают
  языковые ошибки. Не обещается качество большого облачного ассистента.
- С upstream mixed sampler 2B вернула неподдерживаемый `kind:unknown`;
  приложение такой ответ отвергает. После проверки используется greedy.
- 0.8B иногда возвращала обычный текст вместо JSON. Для безопасного
  нефинансового разговора добавлен проверяемый plain-text путь. Повреждённые
  JSON-команды не восстанавливаются и не выполняются.
- Запрос с опечатками «Скока денег астанитса к канцу месица?» проверен
  обеими моделями. После уточнения инструкций 2B выбрала `summary`,
  0.8B — `budgetRisk`: формат верный, **намерение неверное**. До уточнения
  0.8B предлагала незапрошенное открытие счетов; действие отвергается
  проверкой доверенного пользовательского намерения.
- Поэтому дополнительное понимание сложных финансовых формулировок пока
  нельзя считать надёжным улучшением старого движка. Знакомые вопросы и
  однозначные команды по-прежнему идут через детерминированные правила.
  Модель остаётся экспериментальной, выключенной по умолчанию.

## Что проверено только тестами / инспекцией

Это **не** доказательства понимания команды настоящей Qwen:

- Проверки whitelist, выдуманных/архивных ID, принадлежности текущим данным,
  точных копеек, относительных дат, неоднозначного счёта, отрицаний,
  уточнений, устаревшего подтверждения, двойного нажатия и идемпотентности.
- Повреждённый JSON, недопустимые поля, prompt injection в данных,
  рассуждения и финансовые утверждения в потоковом тексте.
- Сохранение истории, merchant-памяти и финансовых соседних файлов
  при смене/удалении/сбое модели; атомарное обновление указателя.
- Отмена/повтор/resume, checksum/HTML/LFS errors, недостаток места,
  повреждённые настройки и установка. Production HTTPS транспорт отдельно
  скачал и проверил официальный config.json.
- Отмена устаревшего запроса во время загрузки/смены модели, budget
  и восстановление обычного базового режима.
- Три отдельных удержания версии, opt-in текстов диагностики и их удаление.

Android lifecycle, PSS/thermal, storage и memory preflight проверены по коду
и сборкой. Реальная нехватка RAM/thermal pressure на устройстве не
симулировалась. Финансовые тесты используют синтетические БД/профили.
Рабочая пользовательская БД не изменялась.

## Оставшиеся ограничения и блокеры

1. **Производительность на Samsung Galaxy A56 8 ГБ не проверена.** Нет
   физического Android-устройства: не проверены on-device inference,
   долговременная стабильность, ощущения UI, скорость, PSS и thermal.
   Инструкция проверки находится в LOCAL_QWEN.md.
2. Семантическая точность моделей недостаточна для автоматических
   финансовых действий: сложные формулировки/опечатки могут быть поняты
   неверно. Все записи требуют штатной формы и сохранения пользователем.
3. Новые libMNN.so и libfinora_local_llm.so имеют LOAD alignment0x4000;
   ZIP alignment проходит. При проверке **всех** native libs найдено
   прежнее `libvosk.so` с alignment0x1000. Следовательно, полная 16 KiB
   совместимость всего APK не подтверждена: для таких устройств требуется
   отдельное обновление и проверка Vosk. Голосовые зависимости в этой
   задаче сохранены. Остальные упакованные ELF — минимум16 KiB.
4. Не проверены настоящая доставка большого пакета/возобновление на
   Android, системное удаление процесса и real low-memory. Host загрузка
   полных пакетов и проверки отказов на fixtures выполнены отдельно.
5. Существующий voice input переиспользован; TTS в базе отсутствует,
   новый TTS не добавлялся. Полностью offline голос не заявляется.
6. Новый JSON истории не добавлен в прежний финансовый backup; модель
   его не удаляет. Новых серверов, аккаунтов, AI-облака или sync нет.

Снимков новых экранов с телефона нет: устройство отсутствует. Успешная
сборка и host inference не выдаются за ручную проверку Android.
