# Награды гардероба Finora

Новые связи компаньонов с достижениями назначены по прямому разрешению пользователя.
Используются существующие ID и условия движка достижений; новые условия,
платная валюта или параллельный механизм открытия не добавлены.
Редкость и секретность компаньонов соответствуют их достижениям.

Снятие/смена компаньона не меняет плащ; снятие/смена плаща не меняет
компаньона. Четыре прежних компаньона и их награды остаются без изменений.
Даты открытия и два слота хранятся в существующем `WardrobeState`/SQLite/JSON.

PNG сохранены побайтно. `WardrobeFit.width` у новых питомцев учитывает
прозрачные поля исходного холста: видимое ядро (alpha>=64) занимает40%
диаметра Финоры, у горизонтального кои44%. Общая ширина PNG поэтому
может быть больше40%; пропорции и исходные пиксели не изменяются.
