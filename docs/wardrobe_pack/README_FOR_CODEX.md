# Finora: 13 выбранных компаньонов + 15 исправленных плащей

Это комплект для встраивания в мобильное приложение. PNG оставлены в исходном виде: 13 пользовательских вариантов из двух пакетов и исправленная серия из 15 плащей с задним расположением. `companions.json` содержит стабильные ID питомцев; `capes.json` содержит стабильные ID плащей; `cape_placement.json` задаёт общую геометрию исправленных плащей.

## Задание для Codex

1. Изучи текущий проект: компонент Финоры, экран «Гардероб Finora», каталог косметики, сохранение экипировки, достижения, способ подключения картинок. Встрой активы в существующую архитектуру и не создавай параллельную систему гардероба.
2. Перенеси `assets/companions/` и `assets/capes/` в подходящий каталог проекта. Подключи все 28 PNG через поддерживаемый стеком механизм: статические импорты/ресурсный реестр, если динамические строковые пути не собираются. Используй ID из JSON как стабильные ключи.
3. Добавь или расширь категории «Компаньоны» и «Плащи». Карточки показывают индивидуальный PNG, название, состояние доступности, кнопки «Надеть»/«Снять». Два независимых слота: один активный компаньон и один активный плащ одновременно. Выбор каждого сохраняется между запусками; снятие одного не сбрасывает другой.
4. Компаньон находится **рядом с Финорой**, вне её лица. Показывай его отдельным элементом, примерно 35–45% видимого диаметра Финоры, сохраняй aspect ratio и прозрачность. Выравнивай у нижней части шара; парящие варианты можно поднять. Адаптируй сторону к экрану и не перекрывай кнопки и текст. В каталоге источники имеют разный размер холста и прозрачные поля: при необходимости используй per-item visualScale/offset в реестре, сохраняя исходные PNG.
5. Плащ рендери **строго behind_character**. Для каждого PNG общий холст 1536×1024: сначала плащ целиком, затем спрайт Финоры в прямоугольнике `(x: 390, y: 130, width: 756, height: 756)` в координатах холста. При изменении размеров масштабируй холст и обе позиции одним коэффициентом; не используй независимые размеры плаща и Финоры. Никакая дуга плаща не должна рисоваться поверх глаз или рта.
6. Если прозрачное тело Финоры просвечивает и плащ становится виден внутри сферы, маскируй/исключай центральную область плаща по силуэту Финоры перед композицией. Сделай маску с корректным антиалиасингом, чтобы край шара оставался гладким. Не закрашивай тело Финоры непрозрачной плашкой, если в приложении оно полупрозрачное.
7. Если выдача предметов за достижения уже реализована, подключи доступность к действующим правилам. Не придумывай ID достижений, условия разблокировки или платные механики. Если её пока нет, оставь явный конфиг разблокировки, совместимый с существующим состоянием гардероба.
8. Проверь композицию на светлой/тёмной теме, узких телефонах и с разными питомцами; выбор, снятие и восстановление после перезапуска. Все картинки должны отображаться из ресурсов приложения без сети. Не деформируй спрайты и не обрезай край плаща. Кои горизонтальный, 1536×1024; проверь его мягкое свечение на обоих фонах.

## Структура

- `assets/companions/`: 13 отдельных PNG.
- `assets/capes/`: 15 отдельных исправленных PNG.
- `companions.json`, `capes.json`: имена, ID и пути.
- `cape_placement.json`: размеры холста, прямоугольник Финоры и слои.

Рекомендация по слоям: фон → `behind_character` (плащ) → маска тела при необходимости → Финора → компаньон как отдельный соседний элемент → UI. Не подменяй выбранные изображения похожими предыдущими вариантами плащей.
