# FINORA: Магистрали — следующий шаг

## Что сделано (1.98.0)

S26: свободная трассировка дорог и путей (VIS-04), метро (METRO-01),
сортировочные станции (HUB-01) и грузовые хабы (HUB-02), фьючерсы на
грузы (FUT-01), экскурсии (TOUR-03).

## Что проверить

1. «Стройка → Дорога»: ведите пальцем по кривой — появится план; два
   пальца двигают карту. «Построить» — дорога плавной линией. Касания
   начала и конца дают прямую под любым углом.
2. То же с «Ж/д путь»; переключатель «Рисовать» возвращает прежний режим.
3. Город от «Регионального центра» → «Построить метро» (технология
   «Метрополитен»).
4. Окно станции → «Сортировочная горка»; окно склада → «Грузовой хаб».
5. «Компания → Биржа» → «Фьючерсы на грузы»; маршрут через курорт →
   «Экскурсия».

## Предлагаемый следующий шаг

Полностью свободная геометрия (дороги вне сетки, развязки любой формы)
— это переписывание симуляции; можно сделать отдельным этапом с
миграцией сохранений. Ещё идеи: трамвайные линии по улицам, грузовые
аэропорты-хабы, сезонные фестивали.
