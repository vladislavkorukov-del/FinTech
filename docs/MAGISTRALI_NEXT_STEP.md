# FINORA: Магистрали — следующий шаг

## Что сделано (2.1.0)

S29: тоннели по форме кривой (VIS-10), клевер с петлями (JCT-03),
турбина (JCT-04), трёхуровневые развязки (JCT-05), линии метро
(METRO-02), фонари (VIS-11).

## Что проверить

1. Проведите кривую дорогу сквозь горы — порталы повёрнуты по дороге.
2. Перекрёсток дорог на 4+ клетки во все стороны → окно дороги →
   «Клевер», «Турбина», «Стек (3 уровня)».
3. «Эстакада» поперёк существующей эстакады — третий уровень.
4. Два города с метро недалеко друг от друга → карточка метро →
   «Линия до …».
5. Ночью вдоль шоссе и магистралей горят фонари.

## Предлагаемый следующий шаг

Съезды-петли с полосами разгона, развязки для ж/д (путепроводы и
многоуровневые станции), подземные станции метро как остановки
маршрутов, дневной трафик-цикл (час пик).
