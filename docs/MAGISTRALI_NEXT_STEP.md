# FINORA: Магистрали — следующий шаг

## Что сделано (1.91.0)

S19: маршруты касаниями по объектам на карте — теперь основной способ
(ROUTE-01); конкуренты (META-09) и поглощения (META-10); звёзды
мегаполиса (META-12); транспорт будущего (TECH-06); коллекция техники
(VEH-14, META-08); песочница (MAP-12); доведены репутация (CITY-12,
CONT-09), исследования через достижения (TECH-08), мягкий кризис (FIN-16).

## Что проверить

1. «Маршруты → На карте»: коснитесь фермы, затем завода — стрелки
   показывают, куда везти; «Создать». Повторное касание последнего
   объекта убирает его.
2. Окно предприятия → «Маршрут отсюда» — сразу режим карты с первой
   остановкой.
3. С 5 уровня — конкуренты: цветная точка у названий;
   «Компания → Конкуренты» — купить.
4. «Компания → Коллекция»: модели и награды; с 8 моделей — «Ветеран».
5. «Настройки → Новая компания → Песочница».
