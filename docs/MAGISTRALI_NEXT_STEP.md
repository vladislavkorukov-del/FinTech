# FINORA: Магистрали — следующий шаг

## Что сделано (1.97.0)

S25: контейнерные терминалы (PORT-01) и контейнеровоз (PORT-02),
ЖД-сигналы (SIG-01), развязки (JCT-01), ипотека для городов (MORT-01),
ночные смены (NIGHT-01).

## Что проверить

1. «Развитие»: пять новых технологий — «Контейнерные перевозки»,
   «Железнодорожная сигнализация», «Развязки», «Ипотека», «Ночные смены».
2. Окно порта → «Построить терминал»: появятся кран и контейнеры. Купите
   «Неву» и пустите её между двумя терминалами.
3. Окно пути → «Поставить сигнал»: у столба горит огонь; два поезда на
   одной линии идут друг за другом.
4. Окно дороги на загруженном перекрёстке → «Построить развязку».
5. Окно поселения → «Ипотечная программа»; окно своей фермы → «Ночная
   смена», ночью окна горят.

## Предлагаемый следующий шаг

Новые идеи по согласованию: метро в мегаполисах, грузовые хабы и
сортировочные станции, биржевые фьючерсы на грузы, туристические
экскурсии.
