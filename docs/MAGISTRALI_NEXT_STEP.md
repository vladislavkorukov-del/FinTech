# FINORA: Магистрали — следующий шаг

## Что сделано (2.0.0)

S28: мосты через озёра и эстакады по форме кривой (BRG-01, VIS-08),
развязки — эстакада, клевер, кольцо (JCT-02), снос кривой целиком
(VIS-07), плавные переходы между дорогами (VIS-09), трамваи по улицам
(TRAM-02).

## Что проверить

1. Проведите дорогу через озеро — встанет мост на опорах.
2. Включите «Эстакада» в панели стройки и проведите дорогу поперёк
   другой — пройдёт сверху, без съезда.
3. Окно дороги на перекрёстке → «Эстакада», «Клевер» или «Кольцо».
4. Окно дороги на кривой → «Снести всю кривую».
5. Продлите магистраль грунтовкой — переход плавный; трамвай между
   поселениями — рельсы на улицах.

развязки из трёх дорог, метро-линии под городом.
