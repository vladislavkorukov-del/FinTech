# FINORA: Магистрали — следующий шаг

## Что сделано (1.83.0)

Доделка P1: VEH-04, TECH-10, ROAD-05; большая карта с рекой
(генератор 5); стройка только касаниями; меню по категориям; новые
тоннели.

## Что проверить

1. «Новая компания на новой карте»: карта большая, её делит широкая река.
2. В режиме стройки двигайте карту пальцем — дороги не появляются.
   Коснитесь начала и конца дороги — план, «Построить».
3. Снос: две клетки в линию — весь отрезок, в панели «вернётся … кр».
4. Транспорт: фильтр «Грузовики» — фура и «Вольт» с замком технологии.
5. «Развитие → Экономика»: рецепты; без «Мукомольного дела» мельницу не
   построить.
