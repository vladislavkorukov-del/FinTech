# FINORA: Магистрали — следующий шаг

## Что сделано (1.84.0)

S12: баланс большой карты, обучение по заданиям, разметка всех дорог,
один въезд к предприятию, море за краем карты.

## Что проверить

1. Новая компания: «Стройка» мигает; в стройке — стрелки над фермой и
   заводом; после дороги мигает «Построить», потом «Маршруты».
2. Дороги всех покрытий — с разметкой; перекрёстки без пятен.
3. Обведите ферму дорогой — заезд только один. В окне дороги у другой
   стороны — «Сделать въездом».
4. Отдалите карту к краю — море, берег, острова.
5. Настройки → «Подсказки обучения» выключают подсказки.
6. «Маршруты → Новый маршрут»: найдите лесозаготовку поиском — сверху
   предложения, кому нужна древесина; фильтры по группам.
