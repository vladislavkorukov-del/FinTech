# FINORA: Магистрали — следующий шаг

## Что сделано (1.99.0)

S27: свободная геометрия дорог и путей (VIS-05) и чистые стыки (VIS-06).

## Что проверить

1. «Стройка → Дорога»: ведите пальцем дугу или змейку — видна кривая
   трассы; «Построить» — дорога ложится ровно по ней.
2. Начните новую дорогу рядом с существующей — конец прилипнет, стык
   ровный, на перекрёстке — плашка без наложений.
3. Два касания — прямая под любым углом; через предприятие — объезд.
4. Машины на кривой едут по ней, без рывков.
5. То же для «Ж/д путь».

## Предлагаемый следующий шаг

Мосты и тоннели по форме кривой, удаление кривой целиком одним касанием,
развязки-клеверы, трамваи по улицам.
