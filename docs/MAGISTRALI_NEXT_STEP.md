# FINORA: Магистрали — следующий шаг

## Что сделано (1.80.0)

Этап S9 — водная логистика: SEA-01…SEA-04 (готов к проверке), перевалка
LOG-14 через склад; доводка ЖД: станция как сигнал (RAIL-08), исправлен
«перескок» на соседний перрон, окно участка пути.

## Что проверить

1. Изучить «Речное судоходство» (ветка «Автопарк», 8 уровень).
2. «Стройка → Порт»: коснуться воды у предприятия у реки, затем у
   второго места у той же воды.
3. «Транспорт» → баржа «Волжанка», маршрут между портами.
4. Два поезда на линии с двумя перронами на конечной: поезд ждёт на
   станции, пока встречный не освободит путь.
5. Коснуться рельсов — окно участка пути.
