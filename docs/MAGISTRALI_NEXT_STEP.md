# FINORA: Магистрали — следующий шаг

## Что сделано (1.93.0)

S21: станки (PROD-10), биомы (MAP-09), субсидии городов (CONT-10),
уникальные заказы (CONT-11); музыка и звуки; свои значки для каждого
груза, машины и предприятия. Каталог механик закрыт: все 203 — готовы.

## Что проверить

1. Звук: музыка на фоне, монетка при доходе, гудок при покупке машины,
   фанфары нового уровня; «Настройки → Музыка / Звуки».
2. Транспорт и магазин: у каждой машины свой значок; в окнах — значки
   грузов.
3. «Контракты» → «Субсидии городов» → «Маршрут» (с 4 уровня).
4. Новая компания: отдалите карту — названия земель; «Настройки → Карта,
   регионы и журнал» — бонусы земель.
5. С 11 уровня: «Развитие → Станкостроение», постройте станкозавод.
