# Finora 1.26.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. Имя файла прежнее; на телефоне приложение теперь называется **Finora**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

- **Finora и Финора**: новое имя приложения и голосового ассистента. Кругляш внизу — живой: моргает, при нажатии радуется (прыжок, «^ ^», кольца) и слушает. Можно обращаться «Финора, покажи расходы…».
- **Приветствие**: Финора здоровается с эмоциями; «Привет» переливается цветами без пятен и наложений; «Финора — ваш финансовый ассистент».
- **Сброс** — в конце настроек, подтверждается свайпом; после сброса без надписи сверху.
- **Настройки и «Ещё» по разделам**, резервные копии — на отдельной странице.
- **Обзор месяца**: одно компактное кольцо, месяц в центре, иконки на секторах, выноска — только по нажатию.
- **Сервисы по-русски**: «чат гпт» → ChatGPT с логотипом и категорией «Подписки» — голосом и при вводе вручную; так же «нетфликс», «спотифай», «ютуб премиум» и другие.
- **Обучение** обновлено под новое.
