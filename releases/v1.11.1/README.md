# Finance 1.11.1

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

**Оптимизация стекла (лаги в 1.11.0):**
- Фон больше не «дышит»: раньше он перерисовывал весь экран 60 раз в секунду, и вместе с ним каждое размытие под карточками. Теперь, когда ничего не происходит, приложение не рисует ни одного кадра.
- Убран шейдер преломления (лишний проход по каждой карточке на каждом кадре) и размытая маска в отрисовке края.
- Блик на плитках доходов/расходов и прочие эффекты — один раз при показе, без повторов каждые несколько секунд.
- Строки длинных списков (календарь, категории, импорт со скриншота) — прозрачное стекло без размытия; размытие только у карточек главной/аналитики и т.п.
