# Finance 1.22.1

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

- **Перенос счетов читает настоящие списки**: название счёта — верхняя (жирная) строка пункта, подпись под ней («Личное») не берётся; значки слева («©», «@», «0») отбрасываются; «P» после суммы — рубль. На скриншоте Дзен-мани находятся все 8 счетов с верными суммами (раньше — один «00000000 Семья Тинькофф Со…»).
- **Перенос счетов в настройках**: раздел «Перенос данных» → «Перенести счета со скриншота».
- **Кнопки приветствия не обрезаются**, в том числе с крупным системным шрифтом.
- **Главная не обрезается после приветствия** (закрывающаяся клавиатура больше не сжимает экран).
- **Логотипы банков на счетах — по желанию**: по умолчанию их нет; в редакторе счёта переключатель «Показывать логотип банка».
