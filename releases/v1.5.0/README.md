# Finance 1.5.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. Application ID, ключ подписи и база сохранены. Android7.0+, ARM/ARM64/x86_64. Для приватного репозитория нужен вход в GitHub с доступом к FinTech.

Все246 встроенных сервисов имеют локальные PNG-логотипы; потерянная пользовательская картинка не скрывает настоящий бренд. Улучшено OCR мелких сумм и тёмных банковских экранов.

**+ → Чек или скриншот**: выберите/сфотографируйте одну операцию или страницу списка операций. Приложение предложит отдельные строки с суммами, датами и категориями. Проверьте, при необходимости исправьте и нажмите «Сохранить выбранные». Возможные повторы не выбраны автоматически. Всё работает локально.
