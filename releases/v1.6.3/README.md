- **Сумма чека — только из строки «ИТОГ».** Не из «ВСЕГО», «СУММА», «СУММА ЧЕКА», наличных, безналичных, сдачи или НДС. Крупный жирный «ИТОГ» теперь дополнительно ищется при чтении всей страницы одним блоком и перечитывается отдельно крупно. Если строка ИТОГ не прочитана или прочтения противоречат друг другу — поле суммы пустое, другие числа не подставляются.
- Исключение: «ИТОГО … СКИДКА … К ОПЛАТЕ» — берётся «К ОПЛАТЕ» (именно столько списано).
