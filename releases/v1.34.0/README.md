# Finora 1.34.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены (в базу добавлены два столбца для иконок платежей — данные не трогаются). Android 7.0+, 64-битные ARM-телефоны.

- **Иконки «из набора» для подписок и обязательных платежей**: в редакторе платежа — кнопка «Из набора» (та же база иконок и цветов, что у категорий), рядом «Своя иконка» и выбор сервиса.
- **Экран загрузки**: надпись «Привет! Я Финора» теперь под Финорой, а не поверх неё.
- **Тактильный отклик сильнее**: вибромотор напрямую (короткий твёрдый импульс на касание, сильнее — на сохранение и удаление), а не слабый системный «отклик на касание». Выключается там же: Настройки → Финора → Тактильный отклик.
- **Вся база в CSV**: Настройки → Резервные копии → «Вся база (CSV)» сохраняет счета, категории, операции, бюджеты, цели, платежи, участников и настройки одной таблицей; «Из таблицы CSV» восстанавливает. Файл открывается в Excel/Google Таблицах; таблица, пересохранённая Excel с «;», тоже читается. Фото чеков и свои картинки в CSV не входят (они есть в JSON-копии).
