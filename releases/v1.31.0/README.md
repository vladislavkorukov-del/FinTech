# Finora 1.31.0 — свой голосовой помощник

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, **только 64-битные ARM-телефоны** (все современные, включая Samsung A56).

- **Финора слышит сама**: своё офлайн-распознавание речи — без звуков записи и без интернета. Нажмите на кругляш — откроется «Финора слушает», слова появляются по мере речи. При первом разе Android спросит доступ к микрофону.
- **«Финора, покажи расходы за июнь»** без касания — включите в Настройки → Финора → «Отзываться на «Финора»». Работает **только пока приложение открыто**; свернули — Финора не слушает.
- **Финора по кнопке питания**: Настройки → Финора → «Финора по кнопке питания» — подскажет, как сделать её помощником телефона. Когда приложение закрыто, она слушает только после этого жеста.
- Распознавание Google осталось переключателем (со звуком, иногда точнее).
