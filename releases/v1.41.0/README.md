# Finora 1.41.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, 64-битные ARM-телефоны.

- **25 картинок Финоры в виджетах** — из присланных владельцем изображений высокого разрешения; каждая аккуратно вырезана по краю плитки (без белых/чёрных полей, углы прозрачные). Исходники и скрипт обрезки — `tool/widget_art/`.
- Какая когда: просрочка → «Не забыть оплатить!»; платёж сегодня → «Платёж сегодня»; ночь → «Всё спокойно»; нет записей за день — с 11:00 по очереди «Запиши расход» / «Записать расход» / «Пора внести расходы», с 19:00 — «Пора внести расходы!»; платёж в ближайшие 3 дня → «Не забудь платёж!»; затем по данным: бюджет превышен → «Пополнить бюджет», ≥ 90 % → «Лимит почти исчерпан», доход сегодня → «Доход пришёл!», мечта ≥ 80 % → «Сбережения на мечту», расходы ±10 % к прошлому месяцу → «Расходы растут» / «Экономия», первые дни месяца → «Бюджет на месяц», нет доходов за месяц → «Учёт доходов», расходы сегодня → «Расходы сегодня» (серия ≥ 3 дней — «Вперёд!»), месяц в плюсе → «Ты в плюсе», есть бюджеты → «Лимит на сегодня», мечта со сроком → «Цель на месяц», пополнение мечты за неделю → «Копилка растёт», бюджетов нет → «Спланируй бюджет», иначе → «Пора проверить».
- В «Финоре-напарнике» реплика с цифрой: «Можно потратить сегодня: 1 250 ₽», «В „Еда“ осталось 800 ₽», «Пришло 50 000 ₽!», «До „Отпуск“ осталось 30 000 ₽», «Сегодня потрачено 640 ₽» и т. п.
