# Finance 1.4.0

Распакуйте Finance-APK.zip и установите Finance.apk поверх прежней версии. Не удаляйте установленное приложение. Application ID, ключ подписи и база сохранены; новая миграция не нужна. Android7.0+, ARM/ARM64/x86_64. Для приватного репозитория войдите в GitHub с доступом к FinTech.

Исправлено сохранение пяти новых тем. В шапке — прозрачная анимированная F. **+ → Чек или скриншот** открывает галерею/камеру; можно поделиться одним изображением из Android в Finance. Сумма, магазин, дата и категория заполняются локально, без сервера. Проверьте черновик и нажмите «Сохранить операцию». Снимок становится вложением операции.

Все290 тестов прошли, analyze/release build/подпись/модели/архив проверены. Работа камеры, Android Share и точность на телефоне отдельно не проверены: Android-устройство не подключено. [Подробный отчёт](../../docs/VALIDATION.md).
