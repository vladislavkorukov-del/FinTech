# Finora 1.32.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, 64-битные ARM-телефоны.

- **Команды и операции снова понимает точное распознавание Google** — «Пятёрочка», «часы 5000» и т. п. распознаются как раньше.
- **Свой беззвучный слух — только на имя**: скажите «Финора» (пока приложение открыто, если включено в настройках) — она ответит «Слушаю!» и откроет распознавание.
- **«Тихое распознавание»** в настройках (выключено): без звука, но понимает хуже.
