- **Живой круг голосового ввода вместо «+»** в нижнем меню — как в голосовом режиме ChatGPT: внутри медленно переливаются мягкие облака цвета темы, круг слегка «дышит», в центре микрофон. Нажатие — голосовой ввод операции; **удержание — обычная новая операция** (как раньше «+»).
