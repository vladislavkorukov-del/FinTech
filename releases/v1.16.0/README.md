# Finance 1.16.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

**Спокойный дизайн — меньше визуального шума:**
- Фон почти ровный: лёгкий оттенок темы сверху и два едва заметных свечения (без цветных пятен).
- Карточки — ровная почти сплошная поверхность с одной тонкой обводкой, без бликов и переливов.
- Доходы/Расходы — нейтральные плитки, цвет только у маленькой стрелки; блик убран.
- Быстрые действия и кнопки в шапке — одинаковые нейтральные, цвет только у значков.
- Ссылки «Все», «+ Счёт», «ноябрь» — серые; свечения за балансом нет.

Цвета тем не изменены. 480 тестов прошли. На телефоне не проверялось.
