# Finance 1.6.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. Application ID `com.finora.fintech`, прежний ключ подписи и база `finora.db` сохранены. Android 7.0+.

- Чек → одна операция с суммой из «ИТОГ / ИТОГО / К ОПЛАТЕ» (в той же строке, на следующей или в правой колонке). Цены, НДС, сдача и способы оплаты не становятся операциями и не суммируются; нет итога — сумма остаётся пустой для проверки. Банковская страница списка по-прежнему импортируется списком.
- В шапке вместо F — общий баланс и валюта; отдельная карточка баланса убрана. «Доход / Расход / Перевод» сразу под доходами и расходами месяца, ниже все счета. Блоки компактнее.
- 364 банка и НКО из справочника БИК Банка России: поиск по названию, сокращению, БИК и регномеру; выбор банка в форме счёта. Оригинальные логотипы банков в эту сборку **не вошли** (см. docs/BANKS.md) — показан нейтральный значок банка.

344 теста прошли (2 пропущены: нет host Tesseract), analyze чистый, подпись прежним сертификатом проверена. Установка обновления на телефоне, камера и OCR на устройстве не проверены — физического Android нет. [Отчёт](../../docs/VALIDATION.md).
