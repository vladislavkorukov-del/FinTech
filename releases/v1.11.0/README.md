# Finance 1.11.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

- **Настоящее стекло вместо градиента**: карточка размывает то, что под ней (цветные «капли» фона плавают и видны сквозь стекло), усиливает цвет, по краю — преломление, как у линзы. Плоско: без объёмной тени и градиентного тела, тонкая светлая кромка.
- **Фон** с более чёткими цветными каплями (четыре, медленно плавают), чтобы стеклу было что показывать.
- Светлых уголков у карточек нет.

462 теста прошли. **На телефоне не проверялось**; эмулятор без аппаратного ускорения не загрузился, поэтому преломление (шейдер, работает только на движке Impeller, т.е. на Android) вживую не видел. Размытие и кромка проверены в рендере Flutter.
