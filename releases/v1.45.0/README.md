# Finora 1.45.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, 64-битные ARM-телефоны.

- **Новые карточки достижений**: у каждого из 54 достижений своя картинка Финоры в высоком качестве (присланные 1706×922, в приложении 1024×553 WebP). В списке и на главной картинка показана без своей рамки — рамку рисует приложение по редкости.
- **Получение — на весь экран**: карточка выскакивает поверх экрана, фон затемняется и размывается, по карточке пробегает блик, вокруг сияние цвета редкости. У эпических и легендарных — конфетти по всему экрану. Ниже — название, условие, редкость и реплика Финоры; кнопки «Посмотреть» и «Далее» / «Отлично!». Несколько наград — по очереди в том же окне («1 / 3»), новые встают в очередь. Закрыть — «Отлично!» или нажатие мимо карточки.
