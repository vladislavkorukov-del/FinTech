# Finora 1.39.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, 64-битные ARM-телефоны.

- **Виджет «Финора-напарник»** (рабочий стол → удерживать → «Виджеты» → Finora → «Финора-напарник», 4×2, можно уменьшить до 3×2): большая Финора, её реплика в облачке, серия дней подряд с записями (🔥) и кнопка «＋ Записать».
  - Цвет фона и Финора меняются по настроению: зелёный — сегодня всё записано, жёлтый — утро без записей, оранжевый — днём напоминает, красный — вечер без записей, 2+ дня без записей или просроченный платёж, тёмно-синий — ночью спит.
  - Серия живёт, пока есть запись сегодня или вчера; вечером, если сегодня пусто: «Серия N дней сгорит в полночь! Запишите хоть одну трату 😤».
  - Нажатие на облачко — сказать голосом, «＋ Записать» — новый расход, остальное — открыть приложение. Обновляется сам каждые 30 минут и после каждой записи.
  - Персонаж и оформление свои (Финора), механика — как у известных «напоминалок с характером».
