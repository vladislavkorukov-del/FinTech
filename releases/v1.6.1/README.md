# Finance 1.6.1

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ подписи и база сохранены. Android 7.0+.

- **Итог чека.** Перед распознаванием выравнивается освещение (тени, выцветшая термобумага). Затем строка «ИТОГ / ИТОГО / К ОПЛАТЕ» распознаётся повторно — крупно и отдельно. Сумма выбирается только из напечатанных чисел и проверяется строкой безналичной оплаты и НДС (20/120, 22/122, 10/110). Если два прочтения расходятся в цифре и ничем не подтверждены — поле суммы пустое, неверная сумма не подставляется.
- **Логотипы банков.** У 11 банков официальные значки с их сайтов: Газпромбанк, Райффайзен, ЮниКредит, ЮMoney, Озон Банк, АТБ, Центр-инвест, Финам, Свой Банк, Кредит Европа, Банк 131. У остальных — нейтральный значок (см. docs/BANKS.md).

Стенд с настоящим Tesseract на синтетических «фото» чеков: итог найден в 59 из 60 и 32 из 40 (было 5 из 60 и 3 из 40 плюс 3 неверных), неверных сумм — 0. Это не фото реальных чеков; на телефоне не проверялось. 371 тест прошёл. [Отчёт](../../docs/VALIDATION.md).
