# Finance 1.23.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

- **Навигация голосом**: нажмите на голосовой круг и скажите команду или операцию.
  - «Покажи расходы за июнь», «покажи доход за год», «расходы за прошлый месяц», «доходы за последние 3 месяца», «сколько я потратил на кафе в мае», «расходы по Тинькофф» — список с заголовком и суммой.
  - «Поменяй тему на зелёную» (синюю, фиолетовую, красную, оранжевую, розовую, серую…) — тема ближайшего оттенка; ещё раз — другой оттенок. «Сделай тёмную/светлую тему», «тема как в системе», «тема Сансет».
  - «Открой настройки», «счета», «мои цели», «бюджеты», «календарь», «категории», «подписки», «семья», «перенос счетов», «аналитика», «операции», «на главную».
  - Всё остальное («Пятёрочка 450») — операция: редактор открывается уже заполненным.
- Удержание круга — ручное добавление, как раньше.
