# Finora 1.40.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, 64-битные ARM-телефоны.

- **15 картинок Финоры в виджетах** (из листа владельца): «Вперёд!», «Запиши расход», «Доход пришёл», «Платёж сегодня», «Лимит почти всё», «Ты в плюсе», «Копилка растёт», «Экономия», «Пора проверить», «Расходы растут», «Цель близко», «Бюджет под контролем», «Отчёт готов», «Есть долги», «Всё спокойно».
- Какая картинка: просроченный платёж → «Есть долги»; платёж сегодня → «Платёж сегодня»; ночь (23–7) → «Всё спокойно»; с 11:00 без записей за день → «Запиши расход»; иначе по данным: бюджет ≥ 90 % → «Лимит почти всё», доход сегодня → «Доход пришёл», мечта ≥ 80 % → «Цель близко», расходы на 10 % больше/меньше прошлого месяца → «Расходы растут»/«Экономия», первые дни месяца → «Отчёт готов», месяц в плюсе → «Ты в плюсе», бюджеты в норме → «Бюджет под контролем», пополнение мечты за неделю → «Копилка растёт», запись сегодня → «Вперёд!», иначе → «Пора проверить».
- **«Финора-напарник»** (4×2) показывает эту картинку рядом с репликой и серией дней; новый **«Финора-стикер»** (2×2) — только картинка, нажатие — записать расход.
