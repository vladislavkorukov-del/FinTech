# Finora 1.48.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+, 64-битные ARM-телефоны.

- **В гардеробе только компаньоны**: «Первая монетка» (первое пополнение мечты), «Кубок мечты» (первая закрытая мечта), «Мини-копилка» (накоплено 10 000 ₽), «Робот порядка» («Порядок в финансах»). Компаньон парит рядом с Финорой; один за раз.
- **Отменено из 1.46–1.47**: шапки, короны, очки, наушники и все плащи убраны вместе с картинками; Финора в нижнем меню и в круге действий — снова без нарядов. Если что-то из убранного было надето, оно просто снимается; полученный компаньон остаётся.
