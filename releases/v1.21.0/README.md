# Finance 1.21.0

Распакуйте Finance-APK.zip и установите Finance.apk **поверх прежней версии, не удаляя приложение**. `com.finora.fintech`, прежний ключ и база сохранены. Android 7.0+.

- **Приветствие при первом запуске**, как при настройке нового iPhone: «Привет» на разных языках → «Как вас зовут?» → «Светлое или тёмное?» → «Перенести данные?» (счета со скриншота / с чистого листа / на примере) → «Всё готово, Имя!». Показывается только на новой установке — при обновлении поверх его не будет. Имя можно поменять в настройках («Ваше имя»).
- **Перенос счетов из другой домашней бухгалтерии по скриншоту.** «Счета» → значок картинки с плюсом (или шаг приветствия). Выберите скриншот списка счетов (Дзен-мани, CoinKeeper, Monefy, банк) — приложение возьмёт названия и остатки, номер карты («•• 4821»), банк и тип счёта (наличные, карта, вклад, копилка, кредитка). Проверьте, поправьте, снимите галочки — и «Добавить счетов: N». Уже существующие счета не дублируются (галочка снята). Скриншот после разбора удаляется.
