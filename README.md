# Finora

Личная и семейная бухгалтерия для Android на Flutter. Оригинальный интерфейс: графитовая и светлая темы, lime/champagne/лавандовый/голубой акценты, карточки счетов, финансовые диаграммы и быстрый ввод суммы.

## Скачать Android-приложение

Готовые APK и ZIP доступны в [GitHub Releases](https://github.com/vladislavkorukov-del/FinTech/releases/tag/v1.0.0). Репозиторий приватный: откройте ссылку под аккаунтом GitHub, имеющим доступ. ZIP содержит тот же подписанный APK; контрольная сумма приложена отдельно.

## Запуск

Требуются **Flutter 3.47.9**, полный JDK 21 (с `javac`), Android SDK API 34/35/36 / Build Tools 36.0.0. Минимальная версия устройства — Android 7 (API 24).

```bash
flutter pub get
flutter run
```

В подготовленной облачной среде:

```bash
cd /workspace/FinTech
source tool/cloud_env.sh
flutter pub get
flutter test --reporter expanded
flutter build apk --debug
```

APK появится в `build/app/outputs/flutter-apk/app-debug.apk`. Его нужно установить на устройство или эмулятор; работающий Gradle не заменяет проверку приложения на Android. Сборка release требует собственного ключа подписи — см. [безопасность](docs/SECURITY.md).

## Что реализовано в коде

- Дашборд: баланс выбранной валюты, доходы/расходы, разница, сравнение месяцев, счета, операции, бюджеты, цели, ближайшие платежи.
- Операции: расход, доход, перевод; редактирование, дублирование, удаление свайпом с отменой; категория/подкатегория, участник, дата и время, теги, получатель, комментарий, статус, чек и геолокация.
- Поиск и фильтры по периоду, типу, счёту, категории, тегу, сумме; текстовый поиск получателя/комментария.
- Счета разных типов и валют, кредитный лимит, банк, последние четыре цифры, архив и исключение из общего баланса.
- 28 стартовых категорий, подкатегории, изменение порядка, выбор иконок и независимых цветов иконки/фона.
- Аналитика: категории расходов/доходов, сравнение поступлений и трат, дневные расходы, баланс, шестимесячная динамика, накопления. Нажатие на категорию открывает операции.
- Бюджеты с прогнозом, финансовые цели с ручным прогрессом, календарь, регулярные операции.
- Локальный семейный профиль с участниками; каждый платёж может принадлежать отдельному человеку.
- SQLite, атомарное сохранение/импорт, JSON с фотографиями чеков, CSV, резервная копия/восстановление SQLite.
- PIN с солью/PBKDF2 и ограничением попыток, биометрия Android, автоматическая блокировка всех маршрутов, скрытие сумм.
- Системные уведомления: платежи, бюджеты, цели, напоминание о внесении операций и отчёты.
- Демопрофиль при первом запуске. Очистка удаляет демонстрационные записи и сохраняет добавленные пользователем записи; необходимые им демонстрационные счета сохраняются с нулевым стартовым остатком.

Это перечень реализации, а не заявление о пройденных проверках. Актуальное состояние проверки — [VALIDATION.md](docs/VALIDATION.md).

## Финансовые правила

Все суммы хранятся в копейках/центах (`int`), а не в `double`. Только проведённые операции влияют на баланс и статистику. Перевод хранится одной атомарной записью, уменьшает исходный и увеличивает целевой счёт, не входит в доходы и расходы. При разных валютах сумма зачисления вводится отдельно.

Общий баланс и аналитика относятся к **одной выбранной валюте**. Неявного сложения RUB, USD и EUR нет. Все предустановленные валюты имеют два десятичных знака; для валют с иным числом знаков нужно расширить денежную модель и импорт. Курсы валют и автоматическая конвертация не подключены.

Цель накоплений — самостоятельный план с отмеченным прогрессом; взнос в её прогресс не списывает деньги со счёта. Для реального перемещения средств создайте перевод на накопительный счёт.

Автоматические регулярные операции создаются при запуске приложения и возвращении в него. Уведомления планирует Android; точное время может сдвигаться из-за энергосбережения. Выполнение финансовых записей в фоне при закрытом приложении не используется. Еженедельные/ежемесячные уведомления предлагают открыть актуальную аналитику.

## Проверки

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test --reporter expanded
flutter build apk --debug
```

Или `./tool/check.sh`. CI с этими командами добавлен в `.github/workflows/flutter.yml`; он ещё не запускался. Разрешённые версии зависимостей сохранены в `pubspec.lock`. Для воспроизводимой установки используйте `flutter pub get --enforce-lockfile`.

## Хранение и резервные копии

Финансовые данные хранятся локально в Android sandbox. PIN не входит в резервную копию. JSON — переносимый формат, включая содержимое чеков. SQLite-копия сохраняет базу, но фотографии остаются отдельными файлами устройства; для переноса на другое устройство используйте JSON. CSV предназначен для таблиц и не является форматом полного восстановления.

Импорт JSON/SQLite **заменяет** текущий набор финансовых данных после проверки. Перед ним сделайте резервную копию. Экспортированные файлы не зашифрованы. Данные не отправляются на сервер; общий профиль на разных устройствах и cloud sync ещё не подключены. Слой repository отделён от интерфейса для будущего добавления синхронизации.
